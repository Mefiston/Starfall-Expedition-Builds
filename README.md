# Starfall Expedition — загрузка игры

Это официальный публичный репозиторий сборок **Starfall Expedition**. Исходный код игры здесь не публикуется.

## Установка и обновление

1. Откройте раздел [Releases](../../releases/latest).
2. Скачайте `StarfallLauncher.exe`.
3. Поместите его в отдельную папку на диске с достаточным свободным местом и запустите.
4. Лаунчер сам скачает актуальную версию игры. После установки нажмите **«Играть»**.

При следующих запусках лаунчер автоматически проверяет обновления. Игра устанавливается в переносимую папку `Starfall Expedition` рядом с лаунчером.

## Предупреждение Windows

Лаунчер пока не подписан цифровой подписью. Windows SmartScreen может показать предупреждение. В этом случае нажмите **«Подробнее» → «Выполнить в любом случае»**.

## Если обновление не загружается

- Проверьте подключение к интернету и повторите попытку кнопкой **«Проверить»**.
- Убедитесь, что игра закрыта и на диске достаточно места.
- Журнал ошибок находится в `Starfall Expedition\launcher.log` рядом с лаунчером.

Все архивы релизов проверяются лаунчером по размеру и контрольной сумме SHA-256 до установки.
